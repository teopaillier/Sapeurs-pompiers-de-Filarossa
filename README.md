# Sapeurs-Pompiers de Filarossa — Site RP

Site statique prêt pour GitHub Pages.

## Contenu
- Accueil
- Grades
- Interventions
- Personnel
- Formation
- Logo intégré
- Menu responsive PC/mobile
- Recherche dans le personnel

## Mettre le site sur GitHub Pages

1. Crée un nouveau dépôt GitHub, par exemple `filarossa-pompiers`.
2. Envoie tous les fichiers et dossiers de ce projet dans le dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Sélectionne la branche `main` et le dossier `/ (root)`.
6. Enregistre.
7. GitHub donnera l'adresse de ton site après le déploiement.

## Personnalisation

- Le logo se trouve dans `images/logo-filarossa.png`.
- Les couleurs et le design sont dans `css/style.css`.
- Les données du personnel sont dans `personnel.html`.
- Les interventions sont dans `interventions.html`.
- Les formations sont dans `formations.html`.
- Les grades sont dans `grades.html`.

Tout est prévu pour un serveur Roblox RP : adapte les noms, matricules, grades et informations selon ton organisation.
